# XRAY Agent Routing

Root selects the cheapest route that preserves the required semantic quality,
evidence, and authority. Exact models and efforts live in Codex configuration,
not this document.

This classifier implements the frozen `xray-oep` Design Packet. It does not
authorize a product behavior, schema, dependency, or compatibility change.

## Routing order

Apply the first matching route:

1. Keep ambiguity, integration, protected-risk decisions, and tightly coupled
   work with root.
2. Send a new or materially revised architecture, API, schema, persistence
   model, compatibility policy, cross-component interface, or visual system to
   `sol_design` before implementation.
3. Send an unchanged qualified failure to `breakthrough_read` after the exact
   trigger in operations.
4. Send fixed-artifact consequential review to `terra_verify` after
   deterministic checks.
5. Send spatial, visual, 3D, novel-pattern, complex-adaptation, or
   semantic-quality-sensitive implementation to `sol_write`.
6. Send conventional contract-complete implementation to `luna_write` when
   delegation saves a turn or enables safe concurrency.
7. Send one bounded repository question to `luna_read` when its answer will
   unblock a decision or independent leaf.

Choose one execution lane before decomposition:

- **root-fast:** one cohesive slice that cannot be dispatched safely;
- **parallel:** at least two independent leaves shorten the critical path;
- **high-assurance:** one consequential claim needs independent review.

XRAY permits root plus at most three open child threads. At most three agents,
including root, may write concurrently, and only in disjoint worktrees with
disjoint primary paths, generated outputs, and exclusive resources.

The existence of a role is not a reason to delegate. Higher reasoning changes
the work performed, not authority, scope, tools, files, retry limits, or gates.

## Design authority

Every implementation cites one frozen Design Packet Bead, version, and
lowercase SHA-256 digest, or an exact architecture-neutral authority. A packet
defines behavior, non-goals, interfaces, invariants, ownership, compatibility,
rollback, risk, reversibility, acceptance, documentation sources, base commit,
dependencies, and resources. A material change creates a new version and
digest.

Root freezes or rejects proposals. A designer does not implement or approve.
A writer does not revise architecture. Terra does not repair. Luna does not
coordinate. Any required boundary change returns to root and, when material,
to `sol_design`.

The V2 host has no V1 `close_agent` action. Root may retain a completed child
for follow-up. When no follow-up is needed, root interrupts the completed lane.
Interruption marks the lane as relinquished but does not itself reclaim its
resident slot. At a full pool, the next spawn replaces the least-recently-used
unloadable relinquished resident. If replacement fails after every child lane
is relinquished, root stops delegation and reports the V2 residency failure.

## Cost and quality

Compare accepted outcomes per turn across the three lanes. Track elapsed time,
follow-ups, repairs, unchanged-artifact reruns, retained worktrees, escaped
defects, and rollbacks. Add parallelism or review only when it lowers total
expected cost without increasing critical defects.
